How it works

  1. Pin the location

    Search or click on the map. No coordinates to type.

  2. Enter the area

    Only the size in square feet. Nothing else is needed.

  3. Location analysis

    We measure nearby schools, hospitals, markets, malls, parks, banks, and the distance to roads, rail, metro and airport.

  4. Model prediction

    A model trained on historical property prices predicts the rate per sq.ft, then multiplies it by your area.

  5. Result you can read

    Rate, total value, an uncertainty range, and the factors the model relied on.

About PropSight AI

PropSight AI is a prototype that turns a map pin into a market-value estimate. It is built with plain HTML, CSS and JavaScript on the front end, and Flask, scikit-learn and SQLite on the back end.

An estimate is only as good as the price data behind it. The bundled dataset is synthetic demo data, labelled as such everywhere it matters. Load real, local transaction or listing data from the admin page and retrain to get meaningful numbers.

What the estimate is not

It is not a guaranteed selling price, a bank valuation, or legal advice. Condition, legal status, construction quality and negotiation all move real prices.
